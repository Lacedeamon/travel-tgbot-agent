#  AI Travel Agent | Telegram Bot

Прототип автономного AI-турагента для Telegram на базе архитектуры **Tool Calling**. Бот ведет пользователя от абстрактного запроса до готового плана поездки, самостоятельно подбирая отели из базы данных, аргументируя свой выбор и имитируя процесс оформления заказа.


##  Ключевые особенности

- **Function Calling (Инструменты):** Нейросеть не выдумывает данные, а транслирует естественный язык пользователя в структурированные JSON-аргументы, которые бэкенд превращает в SQL-запросы к базе данных.
- **Умный поиск с «ослаблением» (Relaxed Search):** Если по строгим критериям пользователя (например, 5 звезд, 1-я линия, до 50 000 руб.) ничего не найдено, алгоритм пошагово и логично ослабляет фильтры, сообщая пользователю о компромиссах.
- **Долговременный контекст:** Бот помнит историю переписки и состояние «корзины» благодаря кэшированию в Redis. Пользователь может в любой момент попросить «изменить даты на август» или «найти вариант подешевле», и агент перестроит план без потери контекста.
- **Богатый UI в Telegram:** Отправка альбомов фотографий (Media Groups), HTML-форматирование текстов, Inline-клавиатуры для бесшовного оформления заказа.
- **Автоматическое сидирование:** База данных и стартовый датасет отелей разворачиваются автоматически при запуске контейнеров.

##  Технологический стек

- **Язык:** Go (Golang)
- **Базы данных:** PostgreSQL 16 (основная БД), Redis (кэш контекста и корзины)
- **LLM Интеграция:** OpenAI API (`sashabaranov/go-openai`)
- **Telegram API:** `telebot.v3`
- **Инфраструктура:** Docker, Docker Compose

##  Быстрый старт

### 1. Клонирование репозитория
```bash
git clone [https://github.com/Lacedeamon/travel-tgbot-agent.git](https://github.com/Lacedeamon/travel-tgbot-agent.git)
cd travel-tgbot-agent

```

### 2. Настройка окружения

Создайте файл конфигурации из шаблона:

```bash
cp .env.example .env

```

Откройте файл `.env` и обязательно укажите два главных ключа:

* `TG_BOT_TOKEN` — токен вашего бота (получить у [@BotFather](https://t.me/BotFather))
* `OPENAI_API_KEY` — ключ от OpenAI или совместимого провайдера.

*Остальные параметры (порты, доступы к БД) уже настроены для работы в Docker по умолчанию.*

### 3. Запуск

```bash
docker compose up --build

```

При первом запуске автоматически применятся SQL-миграции и база заполнится тестовым датасетом отелей. Бот сразу же будет готов принимать сообщения в Telegram!

##  Переменные окружения (`.env`)

| Переменная | Описание | Значение по умолчанию |
| --- | --- | --- |
| `TG_BOT_TOKEN` | Токен Telegram-бота | - |
| `OPENAI_API_KEY` | Ключ доступа к LLM | - |
| `OPENAI_BASE_URL` | Базовый URL для API (полезно для прокси/VseGPT) | `https://api.openai.com/v1` |
| `DB_URL` | Строка подключения к PostgreSQL | `postgres://app:app@db:5432/app?sslmode=disable` |
| `REDIS_ADDR` | Адрес Redis сервера | `redis:6379` |
| `APP_PORT` | Порт Healthcheck-сервера | `8080` |

##  Команды бота

Общение с ботом происходит на естественном языке, но для управления сессией предусмотрены базовые команды:

* `/start` — Инициализация бота и приветствие.
* `/help` — Вызов справки по возможностям AI-агента.
* `/checkout` — Принудительный показ карточки текущего (последнего) заказа в корзине.
* `/reset` — Очистка истории диалога и удаление корзины из памяти Redis (полезно для старта новой сессии бронирования с чистого листа).

##  Структура и архитектура проекта

Проект спроектирован по принципам чистой архитектуры с разделением на слой представления (Telegram-бот), бизнес-логику (AI-агент и логика поиска) и слой данных (PostgreSQL + Redis).

```text
├── config/
│   └── config.go         # Чтение .env и настройка базовой конфигурации приложения
├── dataset/
│   └── hotels_turkey.csv # Исходный датасет с реальными отелями для сидирования БД
├── internal/
│   ├── agent/            #  Ядро AI-агента (Слой оркестрации LLM)
│   │   ├── agent.go      # Логика общения с нейросетью и ведение контекста (Redis)
│   │   ├── cart.go       # Управление состоянием корзины (сборка заказа)
│   │   ├── prompt.txt    # Инструкции и системный промпт AI-турагента
│   │   └── tools.go      # Реализация Function Calling (вызов функций поиска/бронирования)
│   ├── bot/
│   │   └── bot.go        #  Слой представления: Telegram-хэндлеры, маршрутизация, UI
│   ├── hotels/           #  Бизнес-логика домена «Отели»
│   │   ├── book.go       # Имитация оформления заказа и валидация
│   │   ├── relax.go      # Алгоритм мягкого ослабления строгих фильтров поиска
│   │   ├── search.go     # SQL-генератор и динамический поиск по базе
│   │   └── tool.go       # Описание JSON Schema инструментов для OpenAI API
│   └── storage/          #  Слой данных
│       ├── pg/           # PostgreSQL: инициализация и папка с .sql миграциями
│       └── redis.go      # Подключение к Redis (кэш контекста диалогов)
├── .env.example          # Шаблон переменных окружения
├── Dockerfile            # Multi-stage сборка легковесного Go-контейнера
├── docker-compose.yml    # Инфраструктура: App, PostgreSQL, Redis
└── main.go               # Точка входа (DI-контейнер и запуск Healthcheck-сервера)
```
